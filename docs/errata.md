# Game notes

## Campaign access

**DEUS SUPREMUS** is currently selectable even if M-12 remains locked. Matches against DEUS do not award campaign clearance coins. For the standard opponent progression, see [Campaign and unlocks](reference/modes.md#campaign-and-unlocks).

## Browser fullscreen

In the browser build, fullscreen is controlled by the browser page. Use the **[ FULLSCREEN ]** button above the game or the Fullscreen option in the game. Press **Esc** to leave fullscreen; press it again to open the in-game pause menu.

Browser settings are saved in that browser profile, not to an online account or cloud save. Clearing the browser's site data removes those local settings.
